# Apple Wallet Certificates

Place local development certificates here when you have Apple Developer Program access.

Expected files:

- `pass-cert.pem` - Pass Type ID certificate in PEM format.
- `pass-key.pem` - Private key created from your CSR/exported from Keychain.
- `wwdr.pem` - Apple WWDR intermediate certificate in PEM format.

Do not commit real certificates or private keys.
